# Congress Beacon — Yetkili Paneli

Next.js 16 + TypeScript. Kongre/salon/beacon/katılımcı/bilimsel program/
içerik yönetimi ve raporlar.

Kurulum ve mimari için kök dizindeki [`README.md`](../README.md) ve
[`docs/`](../docs/) klasörüne bakın.

```bash
npm install
npm run dev   # http://localhost:3000
npm run lint && npm run build
```

**Not:** Bu proje Next.js 16 kullanıyor — bazı API'ler eğitim
verisinden farklı çalışabilir, bkz. [`AGENTS.md`](AGENTS.md).
